# Левелатор (Levelator)

Интерактивный визуальный инструмент, который помогает детям и новичкам легко понять, как устроена HTML-разметка и DOM-дерево любого сайта. 
Вместо того чтобы показывать сухой код, мы берем скриншот реального сайта и рисуем поверх него границы HTML-элементов (div, span, header и т.д.), разделяя их на цветовые уровни (слои).

## Как это работает?

1. Вы загружаете скриншот любой веб-страницы.
2. Выбираете "уровень" (слой) DOM-дерева, который хотите объяснить (например, 1 уровень — это `<body>`, 2 уровень — основные блоки `<div>`, 3 уровень — кнопки и текст внутри них).
3. Рисуете прямоугольники прямо поверх картинки, имитируя границы элементов.
4. Можете включать и выключать видимость разных уровней, чтобы показать вложенность элементов.

## Возможности

- **Загрузка изображений:** Поддержка любых скриншотов с вашего компьютера.
- **Многоуровневая система:** Изначально 5 цветовых уровней с возможностью добавлять новые (кнопка **+ уровень**).
- **Настройка прозрачности:** Ползунок для изменения видимости нарисованных блоков, чтобы было видно и картинку, и разметку.
- **Горячие клавиши:** Быстрое переключение между уровнями с помощью цифр `1`, `2`, `3`, `4`, `5` на клавиатуре.
- **Чистый режим:** Кнопка "Скрыть интерфейс", чтобы показать результат без лишних элементов управления.

## Технологии

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- **[PixiJS](https://pixijs.com/)**

## Как запустить?

1. Скачайте или клонируйте этот репозиторий на свой компьютер.
2. Откройте `index.html` в любом современном браузере.
